# qtclass 实验路线图（实验室）

本目录是快照样例：验证有效的做法提取到产品与流程，验证无效的就地废弃。当前一个实验——把氛围局与反转关两局游戏的精髓做成可玩的最小循环，供 studio 借鉴。

## 实验：氛围循环（选择 → 投影 → 揭示 → 反转）

**做法**（机制取自 `atmosphere.html` 与 `reversal.html`，公式照抄原作）：

1. **选择在前**：班主先做一周安排——评审筛人、开放免费通道、老人带新人、成品展 / 周复盘、给老人真实项目、暂停招生休整，加门槛 Lv2-6、诱惑卡收 / 拒、从名册挑带人人选
2. **投影是选择的函数**：交作业率逐项摆出，每行标注来源动作〔带人〕〔门槛〕〔招生〕〔妥协〕，改任意选择立刻重算
3. **提交 → 揭示**：传言真假、门槛对比、逐人掷（✓ / ✗）、落到实际交作业率，再摊开这一周的代价与进账（节奏、优质率、疲惫、耐心、口碑、名册增减）
4. **真反转**：学员的一周，处境逐项由班主这一周的选择生成——有没有人带、门槛、过载、班主接的妥协砸到你头上——他再做自己的抉择与判定

**验收标准**：

- 判定率是选择的函数：改选择，投影必变；每行判定追得到来源动作
- 揭示可复现：同种子同结果
- 学员侧环境 == 班主侧选择（带人 / 门槛 / 过载 / 妥协逐项相等）
- 没人带封顶 48%、带人 0.28 压过一切噪音——决定性分层成立

**实验体**：`src/studio/`（Flutter web，实验室 Pages 部署，入口卡可点；9 项测试——6 逻辑、3 界面，CI 跑测试不过不部署）。

**提取去向**：studio 的学习屏（班级经营的决策与投影）、评审页（每行可追动作的判定明细）、B 端 / G 端只读投影（同一份数据换主语）。

## 不做的

- 现金、班规、阶段推进、飞轮：留氛围局本体（`atmosphere.html`），不进实验
- 游戏化（彩带、音乐、收集图鉴）不进工作台
- 河床六节点旅程不改：有集成测试背书，是已验证的部分
